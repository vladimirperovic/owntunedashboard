# Dashboard — pregled i ispravke, 8. septembar 2026.

Polazna verzija: `main`, commit `b3e6e6c`. `git pull --ff-only origin main` potvrdio je da je lokalna kopija ažurna. Pregled obuhvata frontend, prateći Python servis, updater, deploy skripte i postojeću CI konfiguraciju. CI sada pokreće te testove bez `sudo` i bez zavisnosti od mreže.

## Optimizacije i granice pregleda

- Optimizovan je stvarni nepotrebni rad: pozadinski HTTP zahtjevi, preklapanje pollera, duplirani handleri i pretraga reda radi premještanja nove stavke. Nije uveden build sistem niti framework.
- Loader učitava 25 JavaScript i 15 CSS datoteka. Okvirno: 330 KiB JS i 169 KiB CSS bez kompresije, odnosno 95 KiB i 37 KiB zasebno gzip-kompresovanih datoteka. Ovo je računanje veličine lokalnih asseta, ne mjerenje produkcijskog mrežnog saobraćaja; osnovni stylesheet, slike i fontovi nisu uključeni.
- Desktop notifikacije koje je korisnik uključio namjerno nastavljaju provjeru u pozadini, uz zaštitu od preklapanja i zastarjelih odgovora.
- Dalje spajanje CSS-a, uklanjanje starih slojeva i prelazak sa intervala na događaje ima smisla kao zaseban refaktor uz očuvanje vizuelnih testova. Za takvu promjenu nije dokazan neposredan dobitak koji bi opravdao povećan rizik u ovom pregledu.
- Companion API i dalje nema autentifikaciju na LAN-u. CSRF provjere ne predstavljaju kontrolu pristupa za druge uređaje na mreži.
- Za namjerne privatne radio stream-ove administrator mora navesti konkretne hostove kroz `OWNTONE_STREAM_TRUSTED_HOSTS`; provjera se primjenjuje i na svaku redirekciju.
- Uspješan update čuva prilagođene instalirane systemd/nginx konfiguracije, ali nove podrazumijevane promjene tada zahtijevaju ručno usklađivanje. `config.js`, dodatni lokalni artwork i druge datoteke unutar release stabla i dalje treba čuvati izvan njega ili prenijeti u novu verziju. Na neuspjeh se vraća prethodno stablo.
- `OWNTONE_SCHEDULER_ORIGIN` omogućava eksplicitno podešavanje javnog origin-a za prilagođene reverse proxy konfiguracije, naročito HTTPS ili podrazumijevane portove. Vrijednost je npr. `https://music.example.com`, bez putanje.
- Zamjena release-a koristi dva preimenovanja direktorijuma. Nestanak struje/SIGKILL između njih zahtijeva ručni oporavak. Ručni `deploy.sh` i dalje nema potpuno vraćanje nakon kasnijeg neuspjeha servisnih komandi; ne treba ga pokretati istovremeno sa updater-om.
- Fizički HomePod/AirPlay, stvarni stream-ovi, Linux systemd/nginx restart i Safari/iOS na uređaju nisu potvrđeni ovim lokalnim testovima. Za njih ostaju primjenjive ručne provjere iz `DEPLOYMENT.md`.
